# 一、抖音长文正文（可直接发布）

## 你下载的歌，为什么换个设备就放不了？

你在 QQ 音乐花钱下载了一首歌，拷进 U 盘插到车上——**放不了**。

再一看文件名：`xxxx.mflac`、`xxxx.mgg`。用网易云下的也一样，`xxxx.ncm`，除了官方客户端，没有任何播放器认识它。

这不是 bug，是**加密**。

你下载的文件，本质上是一个**上了锁的盒子**：里面装着标准音频（FLAC/MP3/OGG），但每个字节都被打乱过。官方客户端播放时实时开锁，别的软件没有钥匙，自然打不开。

这篇文章讲清楚四件事：

1. 这把锁到底是怎么上的（两家平台是同一个总原理）
2. 钥匙藏在哪里（QQ 音乐有个四代演变的故事，网易云则是另一种思路）
3. 我的开源软件 SonicCheck 是怎么开锁的（以及什么锁它开不了）
4. 最新的 STag 是什么，为什么目前无解

---

## 1. 先澄清：「解锁」到底是什么

在说原理之前，先把这个词钉死：

> **解锁 = 用正确的密码本把打乱的字节逐字节还原，再按标准格式重新封装，补上歌名和封面。**

三个「不是」，一个「是」：

- 解锁**不是**下载——它一首新歌都不会帮你下
- 解锁**不是**破解会员——它只处理你已经下载到本地的文件
- 解锁**不提升音质**——盒子里的货原样取出，没变过
- 解锁**是**：把你已经拥有的歌，从平台的盒子里取出来

---

## 2. 总原理：一本「密码本」（两家平台通用）

QQ 音乐和网易云的加密，用的是同一类思路：**流密码**。

你可以这么理解：

> 加密方手里有一本无限长的「密码本」，把音频的第 1 个字节和密码本第 1 个字节做 XOR（异或）运算，第 2 个字节对第 2 个……一路对下去，原文就变成了乱码。
>
> 解密就是反过来：**拿到同一本密码本，再 XOR 一遍，乱码变回原文。**

XOR 有个很美的性质：**同一个数异或两次等于没动**。所以加密和解密是同一个动作，区别只在于你有没有那本密码本。

所以两家平台的差别**不在锁，在于「钥匙怎么藏」**。下面分开讲。

---

## 3. QQ 音乐：密码本有三本

QQ 音乐按钥匙长度，自动选用三本密码本之一：

| 密码本 | 什么时候用 | 生成方式 |
|---|---|---|
| **map 密码** | 钥匙 ≤300 字节 | 按「位置编号的平方 + 71214」算坐标，去钥匙里取字节，再旋转几位 |
| **分段 RC4** | 钥匙 >300 字节 | 每 5120 字节为一段，每段先空转若干步再逐字节异或 |
| **static 固定盒** | 远古文件，根本没有钥匙 | 一本写死的 256 字节密码本，人人相同 |

> 🛠 **硬核时刻**：三本密码本有个共同特点——**每个字节只看自己的位置编号，不看上下文**。记住这一点，后面讲流式解密时它会救我们一命。

## 4. QQ 音乐：钥匙还套着壳

文件里存的、接口返回的钥匙叫 **ekey**，但它不能直接用——外面裹着腾讯的 **TEA 加密壳**（一种 16 轮的块加密）。

完整链路是：

```
ekey → base64 解码 →（新版 EncV2：两层 TEA + 一次 base64）
     → TEA 剥壳 → 真钥匙 → 推演密码本 → 逐字节 XOR 还原音频
```

老版剥一层壳，新版 EncV2 要剥两层，中间还夹一次 base64 解码——壳中壳。

## 5. QQ 音乐：藏钥匙进化史（四代）

这是最有故事性的部分：

**第一代（远古 qmc）：全民同一把钥匙。** 文件里压根没钥匙，所有用户共用一本写死的 256 字节密码盒。相当于全小区用同一把大门钥匙。

**第二代：钥匙粘在文件尾巴上。** 尾巴里写明钥匙长度，读出来剥壳就能用。

**第三代 QTag：钥匙和歌名打包塞尾巴。** 包装好看了，本质还是粘在锁底下。

**第四代 musicex（现在新版下载的）：钥匙彻底不放文件里了。** 你翻遍整个文件都找不到钥匙，尾巴里只剩两样东西——这首歌的身份证号（`song_mid`）和客户端下载时的原始文件名。钥匙放在腾讯服务器上，**凭登录态按歌领取**。

前三代，任何工具都能离线直接解开；第四代要先「领钥匙」——这就是 SonicCheck 里「导入 QQ 音乐密钥」按钮的由来。

## 6. musicex 领钥匙：五步，全自动

```
① 读文件尾巴 → 拿到歌曲身份证号和原始文件名
② 查本地钥匙库 → 以前领过的直接用，不重复领
③ 只读扫描正在运行的 QQ 音乐客户端内存
   → 找到 "qqmusic_key=" 标记，取出你的登录 cookie
④ 带着 cookie 调腾讯官方接口（CgiGetVkey），按歌换回钥匙
⑤ 钥匙 DPAPI 加密存进本机钥匙库 → 随即开始解密
```

两个细节：

- **文件名必须原样上传**：文件尾巴里记的那个文件名（如 `F0M0xxx.mflac`），不同音质前缀（F0M0/AIM0/Q000…）对应不同钥匙，自作主张改一个字都会领错。
- 实测一批 7 首歌，7 首全部领钥匙成功；失败的会自动重试一轮。

## 7. 专门讲讲：STag 是什么，为什么无解

STag 是 QQ 音乐**最新一代**加密的尾部标记。

它跟 musicex 的区别是：musicex 虽然钥匙不在文件里，但好歹留了「凭登录态按歌领取」的通道；**STag 连领取的通道都没留下**——钥匙既不在文件里，也没有已知的取回方式。

没有钥匙，数学上就无法还原。**这不是工具强不强的问题，是钥匙根本不存在于你电脑里的问题。**

唯一出路：用 **19.43 及以下旧版客户端**重新下载。旧版下载的还是「钥匙在文件里」的格式，就能正常解锁。

## 8. 顺带讲讲：网易云 ncm 的原理（简单得多）

ncm 的思路和 QQ 音乐不同：**每把锁的钥匙，就藏在文件自己的头部**，用 AES-128 加密封存。

而开这层封存的「主钥匙」是**公开的**——所有 ncm 文件通用同一把，早已随逆向工程公开。所以：

> **ncm 解锁全程离线：不需要登录，不需要联网，不需要领钥匙。**

流程：

```
读文件头 → 用公开主钥匙（AES-128）解开钥匙包
→ 展开成 256 字节密码盒（KeyBox）
→ 逐字节 XOR 还原音频
→ 头部自带的歌名/歌手/专辑/封面，一并写回新文件
```

对比一下就明白了：QQ 音乐是「每首歌一把钥匙，藏得一代比一代深」；网易云是「钥匙挂锁上，锁的模具还是公开的」。

## 9. 你可能担心：安全吗？

四件事，说清楚：

- **只读**：扫描 QQ 音乐内存用的是 Windows 只读权限，不注入、不修改客户端的任何数据。
- **加密存**：cookie 落盘前用 **Windows DPAPI** 加密，绑定你的系统账号——换电脑、换用户就是一堆乱码。
- **不出门**：钥匙和 cookie 只存在你自己电脑（`~/.soniccheck/qqmusic_ekeys.json`），不上传到任何地方；网络请求只发往官方接口，没有第三方服务器。
- **可查验**：全部源码在 GitHub 公开，欢迎 review。

---

## 10. 技术流高光：300MB 的歌，峰值内存只有 76MB

老一代解锁工具有个毛病：**把整个文件读进内存再解密**。300MB 的 hi-res 歌，峰值内存要吃掉约 890MB，老电脑直接卡死。

SonicCheck 用的是**流式解密**：每次只处理 8MB，解完写出、再读下一块。

为什么能这样？还记得第 3 节埋的伏笔吗——**密码本的每个字节只看位置编号，不看上下文**。所以第 100MB 处的密码可以直接算出来，不用从头解一遍。这就像一本可以随时翻到任意页的书，而不是一条必须从头看到尾的录像带。

实测：**296.2MB 的文件，峰值内存 75.9MB**，内存占用和文件大小彻底脱钩。

## 11. 开完锁，还顺手做了这些

- **认出真身**：按文件头「指纹」识别内层是 FLAC / MP3 / OGG，给正确的扩展名；
- **补上名牌**：ncm 头部自带标签直接写回；QQ musicex 按歌曲身份证调官方**详情接口**（不是搜索接口——搜索可能搜错歌）联网取回歌名/歌手/专辑，并内嵌 **500×500 封面**；断网或失败自动降级为无标签，不影响解锁本身；
- **清理文件名**：自动去掉 `_EM`/`_EG` 之类的音质尾缀；
- **老实提示**：如果内层是有损格式（MP3/OGG），你选「转成 FLAC」时软件会明确告诉你——**这只是换了个盒子，音质不会变好**。解锁是还原，不是修复。

## 13. 最后，三条必须说的边界

1. **它只处理你已经下载到本地的文件。** 不绕过付费，不下载新歌，连搜歌功能都没有。
2. **STag 格式解不了。** 谁跟你说「全能解」，让他试试 STag。
3. **请只转换你合法获得的文件。** 工具无罪，用途有责。

软件叫 SonicCheck（声鉴·曲库管家），本职是**无损音乐真伪鉴定**（揪出 MP3 转 FLAC 的假无损），解锁是 v1.1.0 的技能。免费、开源（GPL v3）、Windows 绿色版解压即用。

**GitHub 搜 SonicCheck 就能找到。** 祝你的曲库里，没有假无损。🎧

# 三、评论区置顶话术（备用）

> 统一回复：软件免费开源，GitHub 搜 SonicCheck（声鉴·曲库管家），Windows 解压即用。网易云 .ncm 直接解（全程离线）；QQ 音乐新版 .mflac/.mgg 先在软件里点「导入 QQ 音乐密钥」即可解；QQ 音乐最新 STag 格式目前无解（用 19.43 及以下旧版客户端重新下载可解）。注意它只处理你自己已下载的文件，解的是格式锁不是会员锁。毒软报毒是 PyInstaller 打包误报，加白名单即可，源码全部可查验。

## 评论区常见问题预备答案

**Q：会不会封号？**
A：软件只是读取你自己客户端的登录态、调官方接口取你自己歌的钥匙，不修改客户端、不绕过任何付费。但任何第三方工具都没有人能给你 100% 的承诺，介意勿用。

**Q：Mac 能用吗？**
A：目前只有 Windows 版（密钥导入依赖 Windows 的 DPAPI 和内存扫描）。

**Q：解锁后音质有变化吗？**
A：没有。解锁是原样取出，音轨一个字节都不会变好或变坏。软件遇到「有损转 FLAC」还会主动提示你只是换盒子。
