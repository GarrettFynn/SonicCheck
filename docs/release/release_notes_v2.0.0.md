# SonicCheck v2.0.0 发布说明

> 2.0 架构版：结果表格全面重写为 Model/View（万级曲库扫描中可排序、响应即时），主窗口拆分控制器，CI 自动打包上线，启动更新检查。判定与评分口径延续 v1.4.0，**功能行为不变、架构与体验升级**。

---

## 🚀 结果表格 Model/View 重构（本版核心）

- 结果表格从 QTableWidget 迁移到 Model/View 架构，**扫描进行中即可点击
  列头排序、调整筛选**——结果边出边看，不用等扫完
- 2 万行基准：插入 ~1 秒、回填 ~0.35 秒、排序底层 ~4 毫秒、搜索过滤
  ~0.13 秒；列宽/排序状态记忆、右键筛选、双击详情等全部交互保持不变
- "已取消"等行状态改为数据层枚举（替代旧的按显示文本匹配，行为更可靠）

## 🏗 架构与工程

- 主窗口拆分：界面（478 行）与业务控制器（648 行）分离，纯搬移不改逻辑，
  为后续功能迭代降低回归风险
- **CI 自动打包**：推送版本 tag 后 GitHub Actions 自动构建并挂到
  **草稿** Release（ffmpeg 钉版本 9.0.2、打包前跑全量测试）；发布动作
  仍由人工确认
- **启动更新检查**：有新版本时在日志与状态栏提示（仅提示不自动下载，
  可在设置里关闭）；tag 比较会剥离 `+N` 构建后缀
