# SonicCheck v1.3.0 发布说明

> 本版主题：**可视化与体验**。判定结果从"看数字"升级为"看频谱"——每首假无损都能画出断崖位置，并生成可直接分享的 HTML 证据报告。

---

## 🎵 频谱图可视化（本版核心）

- 详情对话框（双击结果行）新增**频谱曲线**：对数频率轴（100/1k/10k 网格），
  **红虚线标注断崖位置、黄线标注 -60dB 截止**——假无损的"垂直跳水"一眼可辨
- 同名对比对话框：两文件**频谱同屏叠加**（青/橙双色），截止频率差异直观可读
- 频谱为 256 点对数分档概要（约 1KB/文件），**判定与评分口径零改动**

## 📄 HTML 扫描报告（甩群利器）

- 工具栏新增「**导出报告(HTML)**」：单文件自包含（汇总卡片 + 明细表 +
  **假无损证据卡**），无外链、断网可看、直接发送
- 证据卡 = 判定原因 + 内嵌频谱图（与软件内渲染同网格同配色）；
  默认仅假无损出卡，明细表完整列出全部扫描行

## ⚙ 设置面板（终于落地）

- 右上角「设置」：线程数 / 每首分析时长 / 默认安全模式 / 质量标记（文本+
  前后缀）/ 打开配置目录，统一收纳
- 与左栏**双向同步**：面板改动即时反映到左栏，左栏参数首次持久化，
  重启保持
- 配置键整体迁移到 `settings/` 命名空间（旧版本升级自动迁移，配置无丢失）

## 🔍 表格与曲库体验

- 工具栏**搜索框**：文件名/路径/标签歌名/歌手任一子串过滤，与"只看真/假
  无损"叠加生效（300ms 防抖，万级曲库不卡）
- 右键菜单新增「**只看此歌手**」「**只看此格式**」快速筛选
- **列宽与排序状态记忆**：关窗保存，重开恢复
- 左栏「**最近 ▾**」：最近 5 个扫描文件夹下拉直切（去重置顶、滚动淘汰）

## 🧪 质量

- 全量测试 3 套件持续绿；新增频谱分档、设置迁移、报告生成的专项冒烟
- 修复：设置面板打开即崩（v1.3.0 开发期内发现并修复，未随任何发布流出）
