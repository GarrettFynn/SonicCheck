# SonicCheck v1.4.0 发布说明

> 本版主题：**引擎能力**。声纹指纹去重补上"签名不同但同一演奏"的最后盲区（改名/不同音质/live 变体），新增疑似升频提示与无头 CLI 模式。**注意：安装包从 123MB 增至约 175MB**（内置 ffmpeg 升级为 full 版以支持声纹指纹）。

---

## 🎙 声纹指纹去重（本版核心）

- 「去重清除」新增可选 **"启用声纹比对"**：对已扫描文件计算 chromaprint
  声纹指纹后再分组，可发现——
  - **改名文件**（歌名被改得面目全非）
  - **不同音质版本**（FLAC 与 320k MP3 内容相同、指标不同）
  - **live / 录音室变体**（签名不同但同一演奏）
- 重复组标注**相似度百分比**（如"声纹相似 93%"），勾不勾随你，默认关闭
- 指纹计算后台进行、**进度可随时取消**；每首约 0.5~2 秒
- 保守阈值（宁漏勿错）：距离 ≤0.30 才判同曲，实测同曲 0.00 / 裁剪变体
  0.04 / 不同歌曲 0.34+，边界清晰

## ⚠ 疑似升频提示

高采样率但有效带宽不足（如 96kHz 但截止仅 16kHz）、或高位深但 DR 偏低的
文件，在状态列提示（鼠标悬停）、CSV 新列、HTML 报告中标记"疑似升频"。
**仅提醒，不影响判定与评分**；分析失败（指标为 0）的文件不会误标。

## 💻 CLI 无头模式

```
SonicCheck.exe --scan D:\Music --out report.html
```

- 无窗口批量鉴定，可选 `--threads` / `--seconds`
- `--out` 支持 `.csv` 与 `.html`（HTML 即证据报告，含频谱卡）
- 默认参数与 GUI 完全一致，同一目录产出相同判定

## 🛠 内置组件升级

- ffmpeg 升级为 full 版（8.1 → 9.0.2，仅声纹功能需要；ffprobe 维持
  essentials），**安装包 123MB → 约 175MB**；全量测试混搭验证通过
