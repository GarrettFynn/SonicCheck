# SonicCheck v2.0.1 发布说明（热修版）

> **v2.0.0 用户请务必升级**：v2.0.0 的「标签改名 / 一键重命名」在点击确认后必定闪退（架构重构漏搬一个方法），已修复。其余功能不受影响。

---

## 🛠 修复

- **标签改名 / 一键重命名确认后闪退**：v2.0.0 重构控制器时漏搬了改名执行方法，
  确认对话框后即崩溃。现按 v1.4.0 逻辑逐字迁回，普通模式与安全模式
  （改名件入安全输出、原件不动）均经端到端回归验证
- **新增闪退日志**：GUI 未捕获异常自动追加写入 `~/.soniccheck/crash.log`
  （绿色版窗口程序此前闪退不留痕迹），便于报告问题

## 📌 说明

- 判定口径、评分、声纹、CLI 等功能与 v2.0.0 完全一致
- 新增测试套件 `tests/test_rename_flow.py`（真实调用链回归，5 套件全绿）
