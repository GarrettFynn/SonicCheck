# SonicCheck v2.0.2 发布说明（热修版）

> 全项目代码审查后的修复批：**静音文件误判修正**（判定可信度）、解锁窗口取消按钮失灵、若干界面行为修复与 CLI 健壮性。v2.0.0/v2.0.1 用户建议升级。

---

## 🎯 判定可信度（本版最重要的修复）

- **静音/极短文件不再被误判为"假无损"**：此前一首开头超过 30 秒静音的
  曲目（长前奏古典、隐藏轨）或数字静音文件，会被判"-60dB截止仅 0Hz
  假无损"。现在这类"数据不足"的文件**不参与真假判定**，状态列悬停会
  提示"⚠ 数据不足（静音或过短）"。真实窄带源（如低码率转制）的判定
  不受影响
- 静音误判曾顺着改名/CSV/HTML 报告传播，本版从源头切断

## 🛠 界面行为修复

- **解锁窗口"取消"按钮真正可用**：此前批量解锁进行中点"取消"毫无反应
  （后台继续解密写文件），只能关窗取消
- **改名后表格行同步**：一键重命名/标签改名后，右键"只看此歌手/此格式"
  对改名行失效的问题修复
- **排序指示器与实际顺序一致**：扫完新一批结果后，表格按表头箭头指示
  的排序重新排列（此前箭头指向旧排序、实际按路径排列，按箭头读表会
  读错）
- **切换文件夹自动清空上次结果**：防止把 A 文件夹的扫描结果误操作到
  B 文件夹（去重/改名会把 A 的文件移进 B 的目录树）
- **开始扫描不再卡界面**：万级曲库的目录清点移入后台（此前在界面
  线程执行，大文件夹点"开始扫描"会假死数秒~数十秒）
- **新版本提示修复**：启动时检查到新版本后，日志与状态栏现在能真正
  显示提示（此前该功能静默失效）

## 💻 CLI 无头模式健壮性

- 参数范围校验：`--threads` 限 1~16、`--seconds` 限 5~120（与 GUI 一致）；
  此前 `--seconds 0` 会把**整库误判为假无损**且退出码为 0
- 退出码分层：0 成功 / 2 参数错误 / 3 目录无音频文件 / 4 全部分析失败
  （便于脚本化调用判断结果）
- 打包版命令行参数错误现在能看到提示（先接管控制台再解析参数）

## 🔧 其他

- 畸形文件的转码错误不再表现为"60 秒超时"（stderr 管道修复，真实错误
  可见）；声纹指纹采集的尾部截断竞态修复
- HTML 报告频谱频率轴与软件内显示完全一致；CSV 防公式注入；
  QQ 密钥导入对网络抖动的容错
- 新增 23 项回归测试（共 8 套件 150+ 断言）+ 槽链静态审计门禁
