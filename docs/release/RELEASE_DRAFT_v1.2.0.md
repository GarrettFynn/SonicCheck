# SonicCheck v1.2.0 —— 大曲库性能 + 去重安全加固（建议所有用户升级）

全项目代码审查驱动的一轮加固：修复 v1.1.0 存量的启动崩溃与去重误报，万级曲库与批量解锁快得多，QQ 登录态落盘安全收紧。

## ⚠ 为什么建议升级

- **启动崩溃**：v1.1.0 扫描过文件夹后重启程序会直接崩溃，已修复
- **去重更安全**：不同专辑的 `01.flac` 不再被误判成重复（旧版批量确认后移走的可能是不同的歌）；现在纯文件名撞车必须内容签名复核，宁漏勿错
- **登录态安全**：QQ 音乐 cookie 在无法加密时不再明文落盘，改为弹窗告知

## 🚀 性能与响应

- 万级曲库扫描不再卡界面（表格批量渲染，3000 行插行 0.13 秒）
- 批量解锁 4 线程并行，吞吐约 4 倍；并行同名输出不再互相覆盖
- 网易云歌单解析 / 解锁窗口文件夹扫描全部后台化：带进度、可取消、不再"未响应"
- 断网批量解锁不再逐首白等：连续 3 次失败自动熔断联网补标签

## 🛡 稳定性

- QQ 密钥内存扫描支持大内存区域（修复偶发"未找到登录信息"）
- GBK 歌单不乱码；`01 - 歌名 - 歌手` 解析修复；歌单复制同名自动消歧不丢歌
- 文件名超长截断 + Windows 保留名处理
- 测试入库 + GitHub Actions CI（128 项断言全绿）
