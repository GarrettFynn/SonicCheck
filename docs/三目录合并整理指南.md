# SonicCheck 三目录合并整理指南

> 现状：你手头有三个相关目录，需要整理成一个干净的"最终绿色打包版本"。
>
> 先理清这三个目录分别是什么：
> - `SonicCheck/` —— **主代码仓库**（已 push GitHub，源码）
> - `SonicCheck-Private/` —— **私有工作目录**（构建产物、测试数据、旧文件）
> - `SonicCheck-设计文档/` —— **设计文档与文案**（PRD、项目日志、抖音文案等）

## 三、具体操作步骤

### Step 1：确认绿色版是否完整

`SonicCheck-Private/dist/SonicCheck/` 已经是一个**完整的绿色版**（314MB），里面已经包含了 ffmpeg。验证一下：

```powershell
cd D:\Dev\SoundProject\SonicCheck-Private\dist\SonicCheck
# 检查 ffmpeg 是否存在
Test-Path _internal\resources\ffmpeg\ffmpeg.exe
Test-Path _internal\resources\ffmpeg\ffprobe.exe
```

如果都返回 `True`，说明绿色版是完整的，ffmpeg 已经被 PyInstaller 打包进去了。

### Step 2：复制绿色版到主仓库目录

```powershell
# 创建发布目录
mkdir D:\Dev\SoundProject\SonicCheck\发布包

# 把绿色版复制过来
xcopy /E /I D:\Dev\SoundProject\SonicCheck-Private\dist\SonicCheck D:\Dev\SoundProject\SonicCheck\发布包\SonicCheck-v1.0.0
```

**`使用说明.txt` 内容（复制粘贴）：**

```
═══════════════════════════════════════════════
  声鉴·曲库管家 SonicCheck v1.0.0 使用说明
═══════════════════════════════════════════════

【这是什么？】
一个无损音频真伪检测工具。拖进一个音乐文件夹，自动帮你找出
所有"假无损"——那些看起来是 FLAC、其实是 MP3 转过来的赝品。

【支持格式】
FLAC、APE、WAV、AIFF（以及同目录下的 .lrc 歌词文件）

【系统要求】
- Windows 10 / Windows 11（64位）
- 内存 4GB 以上
- 不需要安装 Python，解压即用

【使用方法】

1. 解压
   把压缩包解压到任意位置，比如 D:\Tools\SonicCheck\

2. 运行
   双击 SonicCheck.exe

3. 扫描
   把音乐文件夹拖到窗口上，或点"选择文件夹"按钮
   点"开始扫描"，等进度跑完

4. 看结果
   ● 真无损（绿色）—— 放心听
   ○ 假无损（红色）—— 鼠标悬停看原因
   ! 分析失败（黄色）—— 文件损坏或读不了

5. 批量操作（扫描完后可用）
   - 导出 CSV：把结果导出成 Excel 表格
   - 智能重命名：自动给文件名加 [真无损]/[假无损] 标记
   - 去重：找出曲库里的重复歌曲
   - 标签改名：按歌名/歌手标签规范化文件名
   - 歌单导入：粘贴网易云歌单链接，自动匹配本地歌曲

6. 安全模式
   左下角勾选"安全模式"后，所有写操作变成"复制"而不是"直接改"
   新手建议先开这个试几次，确认没问题再关

【常见问题】

Q：提示找不到 ffmpeg？
A：正常情况下压缩包已经内置了 ffmpeg。如果还是提示找不到，
   说明你解压时可能漏了 _internal/resources/ffmpeg/ 文件夹。重新解压一遍。

Q：杀毒软件报毒？
A：这是 PyInstaller 打包的通病，属于误报。加白名单即可。
   本软件开源，源码在 GitHub 上可以查验。

Q：扫描很慢？
A：默认 8 线程，可以在左栏调线程数（1~16）。
   分析时长默认 30 秒，意思是只分析每首歌的前 30 秒。
   调大这个值会更准但更慢。

Q：假无损检测结果可信吗？
A：判"假"的可信度 > 95%（断崖检测是物理层面的硬证据）。
   判"真"的可信度约 85-90%（"没找到假证据"，极少数可能漏网）。
   详细原理见 GitHub。

邮箱：feifeifynn@qq.com

═══════════════════════════════════════════════

═══════════════════════════════════════════════
```

## 六、快速命令（一键执行）

如果你不想手动复制粘贴，把下面这段 PowerShell 脚本保存为 `整理项目.ps1`，在项目根目录运行：

```powershell
# === 配置 ===
$ProjectRoot = "D:\Dev\SoundProject"
$MainRepo = "$ProjectRoot\SonicCheck"
$Private = "$ProjectRoot\SonicCheck-Private"
$DesignDocs = "$ProjectRoot\SonicCheck-设计文档"
$Archive = "$ProjectRoot\SonicCheck-归档"
$ReleaseDir = "$MainRepo\发布包"

# === Step 1: 创建发布包目录 ===
Write-Host "=== 创建发布包 ===" -ForegroundColor Green
New-Item -ItemType Directory -Force -Path $ReleaseDir | Out-Null
Copy-Item -Path "$Private\dist\SonicCheck" -Destination "$ReleaseDir\SonicCheck-v1.0.0" -Recurse -Force

# === Step 2: 写入使用说明 ===
$UsageText = @"
（这里放上面的 使用说明.txt 完整内容）
"@
Set-Content -Path "$ReleaseDir\SonicCheck-v1.0.0\使用说明.txt" -Value $UsageText -Encoding UTF8

$LicenseText = @"
本软件以 GPL v3 许可证开源。
完整源代码获取地址：
https://github.com/GarrettFynn/SonicCheck
"@
Set-Content -Path "$ReleaseDir\SonicCheck-v1.0.0\源码获取方式.txt" -Value $LicenseText -Encoding UTF8

# === Step 3: 压缩 ===
Write-Host "=== 压缩绿色版 ===" -ForegroundColor Green
Compress-Archive -Path "$ReleaseDir\SonicCheck-v1.0.0" -DestinationPath "$ReleaseDir\SonicCheck-v1.0.0.zip" -Force

# === Step 4: 创建归档 ===
Write-Host "=== 创建归档 ===" -ForegroundColor Green
New-Item -ItemType Directory -Force -Path "$Archive\01-源码仓库" | Out-Null
New-Item -ItemType Directory -Force -Path "$Archive\02-设计文档" | Out-Null
New-Item -ItemType Directory -Force -Path "$Archive\03-测试数据与私有文件" | Out-Null
New-Item -ItemType Directory -Force -Path "$Archive\04-已打包产物" | Out-Null

Copy-Item -Path "$MainRepo\*" -Destination "$Archive\01-源码仓库" -Recurse -Force
Copy-Item -Path "$DesignDocs\*" -Destination "$Archive\02-设计文档" -Recurse -Force
Copy-Item -Path "$Private\dev" -Destination "$Archive\03-测试数据与私有文件\dev" -Recurse -Force
Copy-Item -Path "$Private\samples" -Destination "$Archive\03-测试数据与私有文件\samples" -Recurse -Force
Copy-Item -Path "$Private\4个样本文件" -Destination "$Archive\03-测试数据与私有文件\4个样本文件" -Recurse -Force
Copy-Item -Path "$Private\音质扫描器审查.docx" -Destination "$Archive\03-测试数据与私有文件\" -Force
Copy-Item -Path "$ReleaseDir\SonicCheck-v1.0.0.zip" -Destination "$Archive\04-已打包产物\" -Force
Copy-Item -Path "$Private\dist\SonicCheck.7z" -Destination "$Archive\04-已打包产物\" -Force

Write-Host "=== 完成！ ===" -ForegroundColor Green
Write-Host "发布包: $ReleaseDir\SonicCheck-v1.0.0.zip" -ForegroundColor Cyan
Write-Host "归档: $Archive\" -ForegroundColor Cyan
```

> 注意：把脚本中的 `$UsageText` 变量替换为上面完整的 使用说明.txt 内容。
